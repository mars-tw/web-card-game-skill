## 八大面向

1. 美術：做，沿用既有正式卡圖與戰場，整理預覽與航程層次。不新增 2D 原畫；工具未提供可指定／驗證 `gpt-image-2` slug 的能力，不用程序方塊補圖。
2. 按鈕：做，新增控制 ≥44px，手機雙方向與 1366×600 複驗。
3. 選單：做，航程每次一站、可切站、有返回；預覽不蓋常駐設定鈕。
4. 人物：做，新對手沿用 heroRuneFrostfang／heroIsoldLongdusk 正式立繪。
5. 地圖模型：不新增，沿用五張正式戰場，不改 3D／地形。
6. 技能：做，出牌預覽、合法落點、取消、確認後消耗；沿用裂潮。
7. 角色樣子：不改原畫，維持 R67 素材 gate；缺少新姿勢資產列缺件。
8. 動作流暢度：不製作人物姿勢動畫，卡牌拖曳只代表 UI 操作；既有單圖攻擊效果不宣稱為合格人物動畫。保留 impact 時序測試，真姿勢／hurt／death 素材列缺件。
