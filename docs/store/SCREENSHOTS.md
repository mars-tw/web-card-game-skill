# 實際畫面截圖清單

R79／0.12.0。執行 `node scripts/capture-r79-art.js`。港口、五卡試航選取、勝利從正式根入口操作；觀潮台及非致死施放系列使用明示QA準備場景，再以真實按鈕施放／結束回合。標準卡牌攻血與傷害規則未更改，三格之間沒有測試狀態改寫，也沒有圖片後製、縮放、合成介面或改字。來源與連續性收據見 `docs/art/compare/r79/after/capture.json`；檔案雜湊／尺寸見 `docs/evidence/r79-art/verification.json`。這不宣稱QA場景是自然首局或新增試航玩法。

每個主題各有 1290×2796（430×932 CSS、DPR 3）與 2064×2752（1032×1376 CSS、DPR 2）PNG，位於 `docs/store/screenshots/`。

| 畫面檔名前綴 | 真實畫面 | 建議一句說明 |
|---|---|---|
| `harbor-*` | 潮汐領航港口、試航入口、單人離線說明 | 倒下的隨從，留下下一波的力量。 |
| `battle-*` | 正式試航真出三張牌，五種卡圖與士兵選取／敵方目標箭頭 | 在月裂甲板展開你的牌局。 |
| `trial-*` | 非致死同局的實際命中：單一浪牆、定向泡沫、陣亡蓄潮來源 | 讓一道裂潮改變整片戰場。 |
| `tide-chart-*` | 上述QA場景的觀潮台、漲退潮選擇與卡上退場輪廓 | 漲潮破陣，或退潮護住友軍。 |
| `tide-before-*` | 同一非致死場景的施放前，同名ready／waiting並排 | 看準陣形，再決定掀潮。 |
| `tide-after-*` | 同局退浪後，存活敵軍、濕甲板與可繼續的戰鬥 | 浪退了，戰術還在繼續。 |
| `tide-next-turn-*` | 同局下一完整回合，濕痕仍在 | 潮水在甲板留下痕跡。 |
| `victory-*` | 正式潮汐試航勝利與後續航程入口 | 完成試航，再向五站歸航出發。 |

共16張：8畫面×2尺寸。不是實機截圖：這是 headless Chromium 的原生裝置倍率，尚未驗證原生 WebView／狀態列。沒有上傳。人物卡圖是靜態插圖；浪牆為技能補間、耗盡傾斜為紙牌狀態，沒有暗示已具備逐幀人物動畫。逐張檢查見 `docs/art/STORE_QA_R79.md`，改前與改後均保存在 `docs/art/compare/r79/`。
