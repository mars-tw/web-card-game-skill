## 三項設計與驗收

1. 六道潮汐殘局：獨立潮汐研習入口，以既有真卡／核心規則配置固定盤面，分別教陣亡蓄潮、破盾順序、退潮保人、清嘲諷後斬殺、法術與潮術順序、雙目標交換。每題顯示具體目標、提示、立即重試、題目切換與完成回饋；六題從第一天均可選。存完成紀錄與安全回合檢查點，不改收藏。驗收：每題經正式 UI 操作完成；失敗可重試，重載可還原，六題目標不同且不靠加血量。
2. 潮汐預報：港口研習入口的預報對戰，開局公開前三個我方回合的潮向，滿潮只可使用當回合預報方向；一局可反轉一個尚未過去的預報。第四回合恢復自由雙向潮術。提供固定試用盤面，讓觀察、反轉、先退後漲可在短局內體驗。驗收：反轉真改規則、不可二次或改過去回合；重載保留預報與反轉消耗；自然操作勝利。
3. 茉恩的退潮考驗：沿用既有茉恩卡圖，固定手工戰。茉恩預告保護關鍵隨從，敵回合以滿潮退潮加盾，再依固定順序攻擊；玩家必須安排破盾與交換次序。顯示腳本意圖與完成回饋，不稱通用 AI。驗收：退潮真加盾／回血／耗潮，錯誤順序可失敗，正確順序經 UI 勝利；重載與重試正常。
