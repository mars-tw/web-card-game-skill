# 設計規格：具名角色傳說卡擴充包「對座六影」

> **產品**：card-battle-r61（vanilla JS PWA 卡牌對戰）
> **狀態**：僅規劃，不改碼  
> **目標檔案（實作時）**：`templates/card-battle/cards.js`、`core.js`、`battle.js`、`templates/card-pack/pack.js`、平衡 sim  
> **文件語言**：繁體中文（台灣）；id／關鍵字英文代號保留原文  

---

## 0. 一句話目標

把三位具名 AI 對手（哈爾登隊長／維伊魔導師／斯卡拉狼首）做成**可收集、可上場、可進牌組**的傳說角色卡，再補 **凜冬暗影 ×2 + 中立跨陣營 ×1**，讓「對手有名字」升級成「對手可以成為你的牌」；每張帶**互不重複、且不撞現有關鍵字池**的專屬機制，並接上開包權重／pity 與 AI 鏡像牌組。

---

## 1. 現況基線（規格必須對齊）

### 1.1 卡池與陣營（實測 `CARD_POOL`）

| 項目 | 現值 | 備註 |
|---|---|---|
| 總卡數 | **86** | 戰鬥／開包共用單一事實來源 |
| 稀有分布 | 普 25／稀 24／史 23／傳 **14** | 權重 62 / 26 / 10 / **2** |
| 陣營 | 白潮 26／結社 27／荒野 21／**凜冬 12** | 凜冬仍偏薄；本包 +2 傳說暗影 |
| 構築 | `DECK_SIZE = 20`；同名 ≤2；**傳說 ≤1** | AI 無視收藏，玩家需擁有 |
| 變體 | foil 8%；潮印（tide）3%；互斥 | 潮印戰鬥**無數值差** |
| pity | `PITY_LIMIT = 20`；連續無 rare+ 則末卡強制 ≥rare | 現無「傳說專屬 pity」 |

### 1.2 現有關鍵字池（**禁止**再當「專屬新關鍵字」重掛）

`taunt` 嘲諷、`charge` 衝鋒、`battlecry` 戰吼、`deathrattle` 亡語、`divineshield` 聖盾、`windfury` 連擊、`poison` 劇毒、`regenerate` 回復、`lifesteal` 吸血、`rush` 突襲、`frenzy` 狂怒、`spellpower` 法強、`silence` 靜默。

> 角色卡可以**組合**既有關鍵字（例如嘲諷＋新專屬），但「專屬」那一格必須是下表 6 個新代號之一。

### 1.3 現有 trigger／法術效果池（本包新 trigger 上限）

已有：`healHero2`、`damageAny1`、`aoeEnemy1`、`aoeEnemy2`、`buffAdjacent1`、`summonSkeleton`、`summonTwo1_1`、`rebirth`、`drawCard1`、`silenceIfDamaged` 等。

**本包允許新增 core 代號上限 6**（與 6 張角色一一對應；可被動關鍵字則進 `KEYWORDS` + 結算 hook，不一定走 `trigger` 字串）。

### 1.4 三位 AI 對手（現況）

| id | 名 | 軸 | 現牌組簽名 | 行為偏置 |
|---|---|---|---|---|
| `op_ser_halden` | 哈爾登隊長 | control／白潮 | 嘲諷牆 + `captainGreywake` + `highArchivist` | `tauntBias` 高 |
| `op_magister_vey` | 維伊魔導師 | spellburst／結社 | 法強隨從 + 直傷法術 | 先法強再法術 |
| `op_scarra` | 斯卡拉狼首 | aggro／荒野 | 低費衝鋒／突襲 + 臉傷法術 | `faceBias` 極高 |

**缺口**：對手只存在於 `OPPONENTS` 表，**沒有**對應可收集卡；玩家無法「用哈爾登打哈爾登」。

|---|---|---|---|---|---|

## 2. 擴充包定義

| 欄位 | 規格 |
|---|---|
| 包名（UI） | **對座六影** |
| 系列代號 | `set: "hero_shadows_v1"`（卡物件可選欄位；圖鑑篩選用） |
| 張數 | **傳說隨從 ×6**（本規格只規劃這 6 張；不強制同季再塞普／稀） |
| 收集規則 | 傳說 1 張上限；可 roll foil／潮印；`collectKey` 沿用 `id` / `id#foil` / `id#tide` |
| 分解 | legendary 80 金（不變） |
| 世界觀位置 | 編年史「人走進戰場」：三位對手 + 兩位凜冬具名 + 一位跨陣營仲裁者 |

### 2.1 陣營分佈（落地後）

| 角色 | 陣營 | 用意 |
|---|---|---|
| 哈爾登隊長 | `wardens` | AI 鏡像／控制 |
| 維伊魔導師 | `conclave` | AI 鏡像／法強 |
| 斯卡拉狼首 | `wild` | AI 鏡像／快攻 |
| 伊索德·長暮 | `wintershadow` | 凜冬敘事＋控制吸血 |
| 霜牙百夫長·魯恩 | `wintershadow` | 凜冬補厚＋破聖盾交互 |
| 潮間仲裁者·茉恩 | **`neutral`（新建）** | 中立補完；構築不佔單陣營偏置 |

#### 2.1.1 中立陣營落地規則

```
FACTIONS.neutral = {
  id: "neutral",
  name: "潮間中立",
  emoji: "⚖️",
  color: "#94a3b8",
  legend: "不屬四旗，只屬下一次談判的桌面。"
}
```

- **UI**：卡框／fallback 紋理用中性灰藍；不綁定三對手場景色。  
- **構築軟偏置（若已有陣營 ≥8 規則）**：`neutral` **不計入**任一陣營額度，也不阻擋。  
- **圖鑑**：可篩「中立」。  
- 若實作想省事：短期可把茉恩暫掛 `conclave` 並在 flavor 寫中立——**本規格仍以正式 `neutral` 為準**。

## 3. 六張角色卡完整規格

### 3.0 通用資料形狀（實作契約）

```js
{
  id: "heroSerHalden",
  name: "哈爾登隊長",
  type: CARD_TYPE.MINION,
  rarity: "legendary",
  cost: 6,
  attack: 3,
  health: 7,
  emoji: "🛡️",
  image: null, // 可後補 assets/cards/heroSerHalden.png
  keywords: ["taunt", "shieldwall"],
  // trigger: 僅戰吼／亡語型需要
  text: "…", // 規則文，玩家可見
  foil: false,
  set: "hero_shadows_v1",
  heroTag: true,          // 可選：圖鑑「角色」篩選
  opponentId: "op_ser_halden", // 可選：連到 AI；非 AI 角色省略
}
```

同步：`CARD_AXIS`、`CARD_FACTION`、`CARD_FLAVOR`、`KEYWORDS`、（必要時）`core` 結算。

| 陣營 | 白潮守軍 `wardens` |
| 軸 | control |

| 攻／血 | **3／7** |
| 關鍵字 | `taunt`＋**`shieldwall`（列盾）** |
| 戰吼／亡語 | 無 |
| 規則文 | **嘲諷。列盾：相鄰友方隨從受到傷害時，本體改承受其中 1 點（每次傷害事件每名相鄰目標最多轉移 1 點）。** |
| 一句背景 | 城門夜哨上的人；寧可自己裂盾，也不讓後排學會逃跑。 |
| flavor | 他把盾橫在門栓前，好讓別人還有時間喊出自己的名字。 |

| 對應 AI | `op_ser_halden` |

#### 3.1.1 專屬關鍵字：`shieldwall` 列盾

| 項目 | 規格 |
|---|---|
| 中文 | 列盾 |
| icon | 🧱 |
| 觸發時機 | 友方**相鄰**隨從即將扣血（含戰鬥、法術、戰吼、AOE 逐個結算） |
| 結算 | `transfer = min(1, damage)`；該隨從 damage − transfer；哈爾登 +transfer 傷害（走一般受傷管線：可破自己聖盾、可觸發自己狂怒——但哈爾登**不帶**狂怒） |
| 邊界 | 哈爾登死亡／離場後失效；靜默移除 `shieldwall`；對「直接殺（劇毒）」：若傷害事件存在則先轉移 1，再判定是否致死；若效果是「直接消滅不結算傷害」則不觸發 |
| 禁止 | 不得遞迴（列盾傷害不再被另一列盾轉移）；同事件對同一目標只轉 1 |
| 為何像哈爾登 | 穩守、優先護線、把傷害吃在自己身上 |

#### 3.1.2 平衡錨

- **低於** `highArchivist`：同費，少「全敵 2」，交換「被動護鄰」。  
- **異於** `captainGreywake`：船長攻高＋輕 AOE；哈爾登更肉、護鄰、無出場清場。  
- 預期出場身份：控制曲線 6 費牆，不是清場鍵。

| 中文 | 殘響 |
| icon | 🔔 |
| 觸發 | 己方法術 `castSpellEffect` 完成後，若該法術本回合實際造成過 ≥1 點傷害（對隨從或英雄） |

## 5. 開包整合（權重／pity／潮印）

### 5.1 稀有度權重（建議維持總期望）

| 方案 | 內容 | 建議 |
|---|---|---|
| A 維持 | `legendary.weight = 2` 不變 | **採用** |
| B 微降 | weight 2 → 1.5 因傳說池變大 | 不採用（體感過乾） |
| C 微升 | weight 2 → 2.5 | 不採用（金幣經濟膨脹） |

傳說池 14 → **20** 後，單張特定傳說的「自然抽中率」下降約 30%——這是可接受的收集長尾。

### 5.2 傳說子池加權（角色包爽感，不改總權重）

當 `rollCardByRarity` 抽中 `legendary` 時：

```
HERO_SET_IDS = [6 張 hero*]
if rng() < 0.28:
  pick uniform from HERO_SET_IDS
else:
  pick uniform from all legendary in CARD_POOL
```

| 參數 | 值 | 說明 |
|---|---|---|
| `HERO_LEGEND_BIAS` | **0.28** | 抽中傳說時 28% 落在本包 6 張 |
| 期望 | 約每 **(100/2)×(1/0.28)≈** 長線仍稀有，但比純 1/20 更容易「開到角色」 | 可用 telemetry 調 0.22–0.33 |

**潮印／閃卡**：仍在 clone 後 roll；`tide` 與 `foil` 互斥邏輯不變。角色潮印只影響收藏鍵與分解展示，**不影響數值**。

### 5.3 與既有 pity 交互

| 機制 | 現況 | 本包規格 |
|---|---|---|
| rare+ pity | 連續 20 包無 rare+ → 末卡強制 ≥rare | **保留** |
| 傳說 pity | 無 | **可選 P1**，見下 |
| 角色 pity | 無 | **軟保底（建議做）** |

#### 5.3.1 角色軟保底（建議實作，localStorage）

```
key: card_pack_hero_pity_v1
每開 1 包：
  若本包含任一 hero* 傳說 → heroPity = 0
  否則 heroPity += 1
當 heroPity >= 35 且本包將插入 pity 或末卡可替換時：
  以 100% 將「一張非傳說的 rare+ 卡」或「末卡」升級為：
    尚未擁有的 hero* 傳說（優先）；若六張皆擁有則隨機 hero*
  heroPity = 0
```

- **不**與 rare+ pity 衝突：若同包既要 rare+ 強制又要 hero 強制，**一張卡同時滿足**（直接給未擁有 hero 傳說）。  
- 35 包約 3500 金（略高於長線），避免白嫖。  
- UI：開包頁小字「角色保底：x/35」（可 P1 再做顯示）。

#### 5.3.2 明確不做

- 不把 pity 改成「每 20 包必傳說」。  
- 不提高 `DISMANTLE_VALUE.legendary`。  
- 不為角色卡單獨提高 foil 率。

### 5.4 開包 UX

- 抽到 `heroTag` 傳說：沿用 legend-pull 金箔；log／摘要可加「角色」標籤。  
- 首次獲得對應三位 AI 角色：toast「已可將××編入牌組；對戰可鏡像××」。

## 12. 設計結語

「對座六影」不把角色做成數值最大的 10 費神，而做成**人格可操作的 4–6 費軸心**：哈爾登會替鄰座擋刀、維伊會讓咒語留下回聲、斯卡拉會用第一口血叫醒整條獵徑；凜冬的伊索德與魯恩補上暗影的鎖場與破門，茉恩則獎勵玩家把四色放上同一張桌子。開包與 pity 只負責「讓人終於抽到那個名字」，強度驗收則死守至高典藏師等金標——**名字可以傳奇，費用表不行造反**。
