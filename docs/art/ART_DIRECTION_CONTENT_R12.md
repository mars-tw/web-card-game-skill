# R12 身份、狀態與分支結果修正

沿用 ART_DIRECTION.md 七色與 PROMPTS 的完整 MOONREND MARITIME 前綴、厚塗夜海、珍珠貝柱與珊瑚銅天秤。兩張全幅結果插圖實際使用 `image_gen.imagegen`，沒有可核實的模型 slug。原圖與 WebP 均保存於 `assets/art/content-r12/`，詳見本輪 PROMPTS／ASSET_MANIFEST 的來源與 SHA256。

觸發治療路線為站立茉恩、發光回潮與立姿騎士；阻止治療路線為低姿茉恩、無治療光環與受傷跪姿騎士。插圖提供路線識別，實際治療量、是否反攻、承傷與存活血量始終以本局事件數字為準。

頂欄藍袍茉恩頭像由 R10 `moen-ready.webp` 的同身份頭部裁切，不另畫一個角色。Pillow 僅做裁切／縮放與 WebP 編碼。三個持續狀態沿用不同實際肢體畫作：`moen-cast` 為聖盾留守、`moen-hurt` 為護盾碎裂、`moen-recover` 為反攻空檔；傷害反應期間仍以真實事件的 hurt／recovery 幀優先。這些是關鍵姿勢切換，不宣稱高影格角色動畫。原有士兵／騎士攻擊180ms、潮術360ms及獨立滿版卡面圖層保留。

嘲諷沿用 R8 厚塗石牆圖並加短標籤，放在卡牌左側；聖盾仍是右側尖底貝盾，兩者不與詳情鈕爭位。CSS 外框是狀態 UI，不當作新增美術。按住環、回合指向線、治療線2／資源上限6及事件收據皆為 UI 圖解。

新增美術計數為2張生成插圖；另有1張同源頭像衍生圖，3張沿用姿勢不重算。本輪沒有補齊其他所有隨從的正式動畫幀，也不聲稱完成。
