## 新素材、工具與大小

實際工具：**`image_gen.imagegen`**。工具未提供可核實的模型 slug，manifest 的 `model_slug=null`；沒有冒稱本輪已核實 `gpt-image-2`。同一風格前綴與完整提示詞在 `docs/art/PROMPTS.json`。

| 生成原圖 | 接入用途 |
|---|---|
| harbor、battlefield、victory | 夜港首頁、正式甲板戰場、破曉歸航結算 |
| navigator、footman、archer | 領航員／玩家頭像、見習士兵與敵方弓箭手 |
| frame | 所有戰場與開包大卡面，依稀有度處理金屬色 |
| icons | 九枚：對戰、牌疊、羅盤、浪峰、貝盾、航圖、船燈、貝幣、舵輪；主要入口已接用，貝幣保留於素材包 |
| logo、app-icon | 首頁繁中字標與 PWA／App 圖示提案 |

共 **10 張生成原圖**（圖示圖集含 9 枚），轉成 **21 個 WebP＋2 張相容 PNG 卡圖＋2 張 PWA PNG**。WebP 包含新戰場低解析度版、從原圖裁切的水線及頭像，沒有新增生成原圖或冒充不同角色。`assets/art/r75/` 為執行期 WebP，`docs/art/source/` 為不變原圖；尺寸、逐檔 SHA-256、alpha、色彩數據與來源在 `docs/art/ASSET_MANIFEST.json`。原 CREDITS／授權全部保留，新增 R75 來源說明。

後製採 LANCZOS 尺寸調整、alpha 保留、圖集切割及 WebP q82；小圖示 q78、水線 q72、戰場低解析度 q70。戰場曝光 ×1.06，弓手色彩 ×1.08，修正壓縮後門檻；原圖不變。卡框中心 alpha=0，沒有白底或棋盤格烘入。三張角色的實際 WebP 雙閘通過；月白字標的飽和度低於人物門檻，數值保留，不假稱它是合格人物圖。64px 圖在 `docs/art/thumbs/contact-64.png`；這是本線路自審，沒有五人盲測。

與共用舊計畫的格式差異明記：本次實際工具直接回傳 RGBA PNG，保留原始 native alpha、四張 alpha mask、角落值／占用率／bbox 與白底／靛底 fringe 對照，見 `ALPHA_QA.json`、`thumbs/alpha-fringe-review.png`。未假造不存在的 opaque 生成母版，也沒有宣稱已驗收 `gpt-image-2` 去背量產。依本輪壓縮要求，執行期 cutout 採支援 alpha 的 WebP，RGBA PNG 母版留在 source；不將白底圖冒充透明圖。領航員是腰部裁切，底緣接觸邊界與近零角落 alpha 如實記錄。

本輪新／替換執行期圖檔 6,532,609 bytes；扣除被替換的舊卡圖與 PWA 圖示，**美術淨增加 3,167,867 bytes，約 3.02 MiB**。原圖證據另占 26,926,194 bytes，約 25.68 MiB；比較圖與商店 PNG 是開發證據，不在 SW 素材載入清單。沒有建立新的簽章 IPA／AAB，故不是最終原生包體差。
