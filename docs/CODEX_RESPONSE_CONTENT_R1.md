## 三項內容與正式入口

港口按「潮汐研習：殘局・預報・茉恩」；一般對戰也可從設定開啟「潮汐研習／新內容」。研習使用全幅畫面，手機橫向不會被外層分頁列壓縮；選題有返回對戰、返回港口，結果有重試、返回選題與下一道。這些入口都是產品介面，不靠測試掛鉤啟動。

| 新內容 | 做了什麼／怎麼玩 | 完成與存檔 |
|---|---|---|
| 六道潮汐殘局 | 全六題開放選擇。固定真卡盤面，明示本回合目標與解題提示，錯誤交換或提早結束會失敗，可立即重試。 | 每題顯示解題回饋與下一題，六題分別記錄；未完成也能保留安全玩家回合。 |
| 潮汐預報 | 研習內的獨立固定短局。開局公開前三個我方回合「漲、漲、退」，滿潮只可施放當回合潮向。可反轉現在或未來一回合一次，第四回合恢復自由雙向。反轉第一回合可用退潮保住弓手與騎士，再反攻。 | 反轉真改核心規則，錯向零消耗；已用次數與三回合方向一起存檔，重載不能再次反轉。獲勝有研習回饋。 |
| 茉恩的退潮考驗 | 沿用茉恩立繪，明示手工腳本。先結束整備回合；她以六潮退潮，生命 4→7、騎士取得聖盾，留守一回合。玩家先以士兵剝盾、弓手削血、己方騎士收尾，再以漲潮及狼反攻，下一輪斬殺。若拖延，騎士會在後續敵回合出擊。 | 護盾確實留到玩家回合；消耗、回血、交換和勝負均由既有 Core 結算。腳本狀態、對手身份與安全回合可續玩，完成有獨立回饋。 |

六題的觀察與解法不同，沒有改成換血量的普通加關：

| 題目 | 核心決策 |
|---|---|
| 一席換滿潮 | 士兵換弓手，陣亡補最後一潮，再漲潮斬殺。 |
| 先剝貝盾 | 先用低攻剝掉受傷守衛的聖盾，潮傷才有收割效果。 |
| 退浪留弓 | 先退潮，再交換；必須消滅狼且保住弓手。 |
| 浪後的缺口 | 先用浪清掉嘲諷，狼才可攻擊英雄。 |
| 留一滴給海 | 火焰箭把四血騎士打到一血，再漲潮同時完成清場與斬殺。 |
| 兩線同退 | 士兵換弓手、騎士換獅鷲，把兩名敵人同時壓到一血再收割；騎士必須存活。 |

完成紀錄用 `card_tide_content_r1`；既有 `card_tide_session_v1` 儲存完整安全玩家回合。離開敵方行動會回到上一個安全回合。損壞預報與未知研習 ID 會被拒絕，重複完成不重複記錄。試用卡不寫進收藏，不計勝敗、金幣或出牌統計；自動測試另比對確認。
